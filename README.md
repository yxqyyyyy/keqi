# 课期 · 作业与考试提醒

在自己的 Mac 上登录学习通、武汉大学希冀平台，按自己设置的课程范围读取作业、考试和提交状态。程序每天自动更新，将待办写入自己的 iCloud“作业与考试”日历，并设置截止前 **48 小时、24 小时、2 小时**三次提醒。

[GitHub 仓库](https://github.com/yxqyyyyy/keqi) · [下载与版本](https://github.com/yxqyyyyy/keqi/releases) · [MIT 许可证](LICENSE)

iPhone、iPad、Mac 通过 iCloud 日历接收提醒；手机和平板可安装只读 Scriptable 小组件查看近期安排。每个人独立安装、登录和授权，平台会话及任务数据库保存在各自的 Mac 上。

**当前是 macOS 本地程序。**学习通使用正常登录后的网页读取；希冀仅支持武汉大学部署 `https://cslabcg.whu.edu.cn/`。希冀目前读取在线作业，考试需手动添加；其他学校的希冀地址尚未适配。GitHub 用于分享源码，GitHub Pages 不能运行本程序的 Python 后台或原生日历桥接。

## 首次安装

需要一台 Mac、Python 3.10 或以上版本，以及 Xcode Command Line Tools。Apple 日历同步需要在 Mac 开启自己的 iCloud 日历。登录平台时优先使用安装在“应用程序”中的 Google Chrome；未安装 Chrome 时，依赖安装脚本会下载 Playwright Chromium。

1. 下载源码并解压，将项目放在准备长期保留的位置。安装自启服务后不要直接移动目录。
2. 打开“终端”，输入 `cd `，将包含 `server.py` 的项目文件夹拖入终端，按回车。
3. 安装依赖并编译本机日历组件：

   ```sh
   zsh scripts/安装采集依赖.command
   zsh scripts/build_calendar_bridge.sh
   ```

   若未安装 Xcode Command Line Tools，先执行 `xcode-select --install`，完成系统安装后再编译。
4. 双击 `启动作业提醒.command`，或在项目目录执行：

   ```sh
   zsh 启动作业提醒.command
   ```

5. 在这台 Mac 的浏览器打开 [课期](http://127.0.0.1:8765/)。未安装后台服务时，终端需保持运行。

首次构建需要联网下载依赖，日历组件在本机编译和签名。不要复制他人的 `.venv/`、`build/` 或 `data/` 代替安装。

## 设置自己的课程并登录

进入“提醒与设置”，为下面三类分别填写课程名称关键词；**空数组或空白表示不采集该类**，可以只使用其中一个平台：

| 范围 | 设置内容示例 |
| --- | --- |
| 学习通作业 | 概率论、高等数学等自己的课程名称关键词 |
| 学习通考试 | 大学物理等自己的课程名称关键词 |
| 武大希冀作业 | 计算机组成、离散数学等自己的课程名称关键词 |

关键词用于匹配本人账号中可见的课程名称。请使用足够明确的名称，首次同步后与平台课程列表逐项核对；页面改版或未知字段会产生警告，不会把“未读到”理解为已完成。

学习通部分作业只显示月日。遇到缺少年份的截止时间，需要在设置中明确确认年份；程序不会直接猜今年。此设置仅在学习通作业关键词**只匹配一门课**时应用，并绑定这门课的课程和班级；多门匹配时需要缩小范围。修改课程范围或年份会清除旧绑定，下一次读取时重新核对和绑定。平台已有完整日期时，以平台日期为准。

随后进入“平台接入”，点击相应平台的登录按钮，在弹出的**平台原登录页**自行输入账号、密码、验证码或完成校园统一认证，再点击“立即同步”。密码不需要发给开发者，也无需输入程序自制的账号表单。

日常读取使用保存的登录会话在后台请求，不会自动打开 Chrome。只有主动点击登录按钮时才打开专用浏览器。登录失效后需本人重新登录，程序不绕过验证码，不自动提交作业、开始考试或作答。

新安装默认关闭每周大物固定作业。如需这项线下作业，在设置中开启并设置截止时间、可选结束日期。周六 24:00 按周日 00:00 保存，提交后在程序里勾选当周完成。已有使用者升级会保留自己的设置。

## 接通日历提醒

1. 在 Mac 系统设置中开启自己的 iCloud 日历。
2. 在课期“提醒与设置”点击“同步到 Apple 日历”，本人允许“作业提醒日历桥接”**完整访问日历**。程序需要读取已有事件以更新安排和取消已完成任务的提醒。
3. 在 Mac 日历中确认出现“作业与考试”日历，并核对一条待办的截止时间及 48／24／2 小时三个提醒。
4. 在 iPhone、iPad 上使用同一 Apple 账户，开启 iCloud 日历和“日历”通知，核对同一条事件。

首次成功同步后自动开启后续日历更新：新增任务、修改截止时间及确认完成都会更新程序管理的事件。只有带 `studydeadline://task/…` 标识的事件由程序管理；其他日程保留。重复同步会更新原事件。

考试事件目前放在**最晚提交时间**，三次提醒均相对于该 DDL；开考时间另显示在界面和事件备注里。请另外核对固定开考安排。首次同步时已经过去的提醒点不会补发。

## 每日同步与提交状态

- 默认北京时间每天 **08:00** 读取，可在设置中修改或关闭。睡眠错过后，会在恢复运行、联网且会话有效时补读；启动和手动同步也会读取。
- 每次完整读取后更新安排及提交状态；新条目自动加入，明确已提交或已批阅的条目标记完成，并取消本程序的后续日历事件。未知状态保留待办并提示核对。
- 在 48／24／2 小时提醒前 10 分钟内额外核对提交状态；2 小时提醒前最后 3 分钟内再做一次临近复查。
- **Mac 需要运行、联网且平台登录有效**，才能采集新作业、发现提交和取消提醒。Mac 睡眠、关机、断网或登录过期时无法及时复查。
- 已经同步到设备的日历事件仍可提醒；跨设备更新取决于 iCloud 同步和设备联网情况。通知也受系统通知权限、专注模式等设置影响，已弹出的通知不会追溯撤回。

可以点击“立即同步”主动复查，也可以手动勾选完成。线下固定作业只能由本人确认完成。程序不会把本次未读到的任务自动标记完成。

## iPhone、iPad 界面和小组件

在 Mac 程序“提醒与设置”复制手机访问链接，使用同一可信 Wi-Fi 下的手机 Safari 打开。链接包含本地配对码，仅用于自己的设备，不要公开。`127.0.0.1` 只表示当前设备，Mac 上的地址不能直接用于手机。

网页适配手机和平板，可用 Safari“分享 → 添加到主屏幕”保存入口。它仍是局域网网页，离开该网络后不能访问 Mac 后台。

小组件安装入口也在设置中：复制脚本到各设备的 Scriptable，运行一次并授权读取日历，然后添加主屏幕组件、选择“课期”脚本。小号显示最近一项，中号三项，大号五项，iPad 超大号最多八项。详见 [小组件安装说明](widgets/README.md)。

小组件只读取设备本机已通过 iCloud 同步的日历，不提交状态、不写日历，无需每天打开 Scriptable，也无需与 Mac 处于同一 Wi-Fi。刷新由 iOS／iPadOS 安排，代码中的 15 分钟是最早刷新时间，不保证准点。48／24／2 小时提醒由系统日历负责。

新版小组件会将 24 小时内待交作业显示为暖橙色，2 小时内红底白字并提示“尽快提交”。已安装旧脚本的设备需替换完整脚本、运行一次，才能启用新外观。提示以设备已同步日历为准。

## 安装登录自启服务

首次安装、设置和同步通过后，可在项目目录执行：

```sh
# 安装或恢复本项目后台服务，登录 macOS 后自动运行
.venv/bin/python scripts/manage_background_service.py --install

# 只读查看服务状态
.venv/bin/python scripts/manage_background_service.py --status

# 仅预览服务配置，不修改系统
.venv/bin/python scripts/manage_background_service.py --dry-run

# 停止服务并移除登录自启，保留任务数据和日志
.venv/bin/python scripts/manage_background_service.py --uninstall
```

服务配置为 `~/Library/LaunchAgents/local.studydeadline.server.plist`，日志为 `~/Library/Logs/StudyDeadline/stdout.log` 和 `stderr.log`。管理脚本验证配置归属，拒绝接管同名的其他项目服务。卸载服务不会删除已写入 iCloud 的日历事件。

启动器会识别已运行的服务并打开界面。迁移项目前，先在原目录卸载自启服务，再在新目录安装；更新 Python 或重建虚拟环境后，也应重新安装服务。切换 Wi-Fi 后恢复后台服务，再从设置复制新的手机访问链接。

## 数据与隐私

`data/` 包含本人的任务 SQLite 数据库、配对码、浏览器配置和平台会话；会话文件以受限权限保存。不要把此目录发给他人、上传 GitHub 或放进公开问题附件。JSON 导出不包含平台 Cookie、密码和配对码，但仍包含自己的课程和任务内容，分享前需自行检查。

源码不带任何人的登录状态。每位使用者需要在自己的 Mac 重新安装依赖、登录账号、设置课程并授权日历。本程序没有集中收集账号的服务，也没有供多人共享的云端账号数据库。

局域网访问使用 HTTP 和配对码，适合自己可信 Wi-Fi 下的设备；不要把服务端口开放到公网。已经同步的 iCloud 日历和系统提醒不依赖局域网网页保持打开。

## 开发和检查

开发前先停止自启服务，避免占用同一端口。可选择前台运行：

```sh
# 仅本机访问
.venv/bin/python server.py

# 同 Wi-Fi 设备通过配对链接访问
.venv/bin/python server.py --lan

# Python 离线测试：不需真实登录，不写系统日历
.venv/bin/python -W error::ResourceWarning -m unittest discover -s tests -v

# JavaScript 语法和模拟小组件测试；需要另行安装 Node.js
node --check web/app.js
node tests/test_widget.js
```

前台用 `Ctrl+C` 停止。平台页面改版、登录策略及字段差异会影响覆盖，应根据程序提示核对原平台。当前不保证所有学校、所有课程页面版本都可读取。
